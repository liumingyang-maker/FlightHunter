## 下一轮主线开发建议（按业务目标统一完成）
1. **抽奖“聚合候选 → 奖品类别识别 → 真正主办方/官方细则定位 → 资格筛选 → 用户可判断是否参赛”** 的完整可用流程。普通奖品不能误进机票抽奖推荐；候选和已核实继续严格区分。优先实测至少一条官方或可溯源的旅行奖品。
2. **行程福利“明确日本目的地/日期 → 可合法抓取的商家或旅游局优惠活动 → 规则/领取/可用期证据 → 匹配 → 中文说明及提醒”**。独立旅游指南属于线索来源，不等于官方优惠和已领券凭据。
3. **长期运行证据**：脱敏记录真实 source URL、抓取时间、状态、候选数、业务有效数、通知状态，并区分“扫描完成”“发现新线索”“核实成功”“可报名/可用”。
4. 启用**无人值守处理任意外部 URL** 前，仍须把 DNS 校验与实际连接目标绑定，或在网络隔离环境中运行。避免为了赶进度弱化安全边界。

仅在以上业务集成时一并处理报告中的归类、名称及统计问题，不需要因这些普通缺陷单独启动下一轮审查。
