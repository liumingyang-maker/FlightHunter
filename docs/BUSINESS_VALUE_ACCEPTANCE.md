## 1. 国际机票情报：真正明确匹配出发城市有多少？

| 级别 | 含义 | daily 库当前 |
|---|---|---:|
| **explicit_city** | 标题/解析含偏好城市（如成都→TFU） | **1** |
| **national_multi_city_pending** | 全国/多城适用，**未**断言含重庆成都 | **11** |
| origin_unknown | 出发地未知 | **0**（本轮视图） |

**改进（本轮）：**
- 多城市标题提取（北上广/成都 → PEK/PVG/CAN/TFU）  
- 目的地铁/航司补全（东京/曼谷/全日空…）  
- **全国多地 ≠ 自动等于重庆/成都**（标 `national_multi_city_pending`）  
- 国内目的地（如银川）不再当国际情报  
- 示例：`北上广/成都-赫尔辛基` → **TFU + HEL + explicit_city**

**回答：** 当前默认偏好下，**明确匹配城市 = 1 条**；其余以全国待核实展示，**不丢弃、不硬算成重庆成都**。

## 2. 免费国际机票抽奖：能否判断中国内地用户参与条件？

| 能力 | 状态 |
|---|---|
| 自动发现 + 官方 URL | **能**（VISITKOREA 美食栏 → 1594420） |
| 开放日期 | **能**（OCR 2026-10-26～11-22 → open） |
| 奖品含往返机票 | **能** |
| 是否适用中国内地出发/往返 | **不能断言** → `china_outbound_relevance=unknown_origin_pending` |
| 内地用户是否 eligible | **不能**（非韩国常住限制已解析时仍需真实档案） |
| 中文参加指南 | **能自动生成**（入口/日期/资格 unknown/不代提交） |
| 官方报名入口探测 | **能**（event.do 只读；不提交） |

**回答：**  
能完整判断「活动真实、仍开放、奖品含机票」；**不能**在无用户国籍/居住档案时判断「内地用户可参加」——保持 unknown，**不假装已符合/已报名**。  
当前适合内地用户的「已核实可报名免费机票」= **0**（开放机票活动出发地适用性未确认）。  
汽车/现金类不进核心推荐（`not_travel_ticket`）。
