## 真实来源抽检

本批于 2026-10-30 至 10-31（中国时区）使用项目适配器遵守 robots，只读 `https://flynext.hk/`：HTTPS 200，列表解析 4 条，隔离内存数据库中港澳频道 2 条；`safe_get` 同样 HTTPS 200。Peach 及国泰文章明确 HKG，HK Express 的列表摘录本身没有明确出发地，故保留 unknown；此前凭品牌推断 HKG 的做法不再使用。详情页可能包含额外事实，本批未新增自动抓取详情逻辑，不能把列表未知当作来源没有香港出发活动。

Peach 同一文章含 HK$1,600 和含行李 HK$2,150 两种价格，本批保守不输出单一票价；这是避免错误绑定的产品取舍，并非声称没有报价。FlyNext 样本及单次网络成功均不能证明库存可买或来源长期稳定。

## 未解决或需要下一步复核

1. **浏览器网络边界：partial。** 本批连接绑定只覆盖 `safe_get` 和 HTML/RSS 适配器；明确允许自动化的浏览器仍需单独审查页面重定向、子资源、DNS 重绑定与域名变更，不应将本批当成全站安全完成。
2. **HTTPX 兼容：partial。** HTTPX 没有公开的网络 backend 注入接口，当前连接池挂接使用其内部 `_pool._network_backend` 并在结构不兼容时失败关闭；`httpcore` 明确作为依赖。升级 HTTPX/httpcore 时须重跑集成及真实 HTTPS 测试；显式传入的自定义 client 属于调用方可信边界。
3. **抽奖中国出境正向闭环：partial。** 候选不直接标核心是安全取舍，但完整官方证据驱动的正向核心推荐仍需产品/数据模型工作；此轮不虚构资格或活动。
4. **旅行日期：partial。** 本次仅筛选已有、可解析的 `FareDeal` 时间窗口；多数公开来源没有结构化出行日期时仍显示未知，不代表已完成所有来源的日期抽取。
5. **数据库启动：partial。** 本次防止 Web 启动隐式改已有库，但已有库仍可能版本过旧，仅警告并继续启动；CLI 路径也需单独梳理。正式升级、回滚和备份须在授权后进行。
6. **通知持久化与跨源合并：partial。** 成功/失败重试仍需真实桌面、进程中断、并发及跨源事件级复验；进程在外送和事务提交之间崩溃的精确一次语义没有证明。
7. **104 项、72 小时、真实 toast、完整公网安全：NOT_TESTED。** 个人每日可靠使用及完整 V1 不因本批测试通过自动转为 YES。
