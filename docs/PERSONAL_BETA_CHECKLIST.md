# FlightHunter 个人测试版（Beta）完工清单

**目标：** 你自己本地每天能用：情报 + 抽奖线索 + 行程福利，稳定、不误报、不重复打扰。  
**不是：** 公网上线、商用、104 项全绿、实时报价 API。  
**预计：** 1–2 周（含 72h 跑时间 + Codex 一轮复验）

---

## 一、功能收尾（工程，约 2–4 天）

### A. 抽奖核心推荐端到端（C14-03 剩余）
- [ ] `auto_verify` 成功后 tags 写入 → 页面/API 读取一致
- [ ] 正例：官方 + 国际目的地 + 内地出境 → 仅此时标 core
- [ ] 负例：国内航班 / 不包括大陆 / candidate / 社区源 → 全部非 core
- [ ] 证据撤销：核验失败/过期时自动降级
- [ ] 隔离库端到端测试（不只调判定函数）

### B. 浏览器安全 partial 收口
- [ ] 文档/UI 明确「外站浏览器自动化 = partial」
- [ ] 仅 `automation_policy=allowed` 站点可预填（已有）
- [ ] 真实外站默认 MANUAL_ONLY（已有）
- [ ] 评估是否值得做 Playwright 连接 IP 绑定（可标 blocked 进测试版）

### C. 跨源合并（可选，测试版可保守）
- [ ] 保持保守不误合并即可
- [ ] UI 显示「同活动多来源」链接，不要求全自动合并

---

## 二、稳定性与验收（必须，约 3–5 天含等待）

### D. 72 小时连续运行
- [ ] 启动 Worker（daily_usage 配置，interval 1800）
- [ ] **不重置** `OBSERVATION.json` `started_utc`
- [ ] 记录：每 12h 心跳、来源健康、通知次数、错误日志
- [ ] 断网/恢复至少各一次（拔网或断 Wi-Fi）
- [ ] 产出：`docs/72H_RUN_REPORT.md`（真实时间戳，不伪造）

### E. 真实桌面通知
- [ ] toast 成功 → 重启进程 → **不重复弹**
- [ ] toast 失败（禁用通知权限）连续 3 次后停止
- [ ] 中文长标题不报 GBK 解码错
- [ ] 产出：截图或时间线记录

### F. 真实来源抽检（至少 3 次，不同时段）
- [ ] FlyNext 首页只读 → 列表条数、港澳频道条数
- [ ] 价格/币种/日期与人工核对一致（抽 2–3 条）
- [ ] robots/403 来源标记 blocked，不硬抓
- [ ] 记录进验收报告

### G. 104 项矩阵填证据（非 100% 必须全绿）
- [ ] 每项标：PASS / FAIL / NOT_TESTED / BLOCKED
- [ ] PASS 必须有证据链接（测试名 / 日志 / 截图）
- [ ] 未测项诚实写 NOT_TESTED，禁止假绿
- [ ] 产出：`docs/REQUIREMENTS_MATRIX.md` 更新

---

## 三、独立复验（约 1–2 轮 × 1–3 天）

### H. 交 Codex/GPT
- [ ] 打包 zip（`scripts/pack_codex_review.py`）
- [ ] 任务书：`docs/CODEX_SPRINT_CLOSEOUT_HANDOFF.md`
- [ ] 按其意见整改（预计 1 轮小改 + 1 轮确认）
- [ ] **不自签关单**

### I. 风险项（测试版可带病发布但要写明）
| 项 | 测试版策略 |
|---|---|
| 浏览器 IP 绑定 | 标 partial，禁真实外站自动填表 |
| 跨源合并 | 保守，宁可重复不误合并 |
| 通知 exactly-once | 文档写 at-most-once + ≤3 |
| 跨源 entity ID | 保持 partial |

## 四、你自己用的「日常习惯」（测试版体验）

### J. 启动与巡检
- [ ] 开机自启 Worker（已有 Startup bat）
- [ ] 每日看一眼 Web `:8765` 四频道
- [ ] `worker-status` / `source-health` 有异常再处理
- [ ] 备份：每周复制一次 `data/daily_usage/fh_daily.db`

### K. 明确不做的事
- 不自动购票 / 付款 / 报名
- 不绕过 robots / CAPTCHA
- 不把「报道价」当可买价
- 不重置 72h 观测

## 六、测试版完工定义（DoD）

满足以下即可宣布 **个人测试版**：

1. 72h 连续运行有真实日志  
2. toast 不重复、失败有上限  
3. FlyNext 抽检 3 次数据一致  
4. 104 项矩阵填完（允许 NOT_TESTED/BLOCKED）  
5. Codex 一轮复验：安全/语义类 P1 无新 FAIL  
6. 你自己试用 2–3 天不被误报打扰  

**完整 V1.0 正式完工**还需：104 项尽量全绿、跨源合并闭环、更多来源覆盖、更长稳定运行——那是下一阶段，不挡测试版。
