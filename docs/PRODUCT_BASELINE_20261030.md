# FlightHunter V1.0 产品需求基线（2026-10-30）

**状态：** 用户确认的产品方向正式调整（非 V2、非重写）  
**HEAD 基线：** `0f77f10` 起在 `develop` 上演进  
**原则：** 保留现有架构/DB/测试/OCR/调度/安全；不强制实时报价供应商。

---

## 1. 产品定位

个人使用的 **国际旅行机会情报助手**（本地优先 FastAPI + SQLite + Worker）。

| 优先级 | 模块 | 一句话 |
|---|---|---|
| **P1** | 国际特价机票情报雷达 | 发现真实促销/错价/漏油/会员日情报 + 来源链接，用户自行查询购买 |
| **P2** | 免费国际机票抽奖猎手 | 全球发现；优先中国内地出境相关免费机票/旅行套餐 |
| **P3** | Trip Benefits | **仅在用户确认真实行程后** 搜寻目的地省钱福利并生成中文指南 |

### 明确取消/降级的需求

| 旧强制项 | 新口径 |
|---|---|
| 实时机票报价 API / `urgent_verified` 可购价 | **不作为 V1.0 必做**；情报 + 原始链接即可 |
| 无报价供应商导致雷达不可用 | **否**；情报模式为完整能力 |
| 新闻价 = 实时可买 | **禁止** |

历史报价适配器代码 **保留**（未来可选接入），配置默认关闭。

## 2. P1 国际特价机票情报雷达

### 2.1 出发地

- **单城/机场**、**多城/机场**、**全国出发（中国内地）**
- 默认：`CKG`（重庆）、`TFU`+`CTU`（成都）
- 可扩展：北京、上海、广州、深圳、杭州、武汉、昆明等
- **港澳规则：**
  - `HKG`、`MFM` 独立可选，**不**自动并入「全国=内地」列表
  - 全国出发 = 仅中国内地机场
  - 用户可在内地全国之外 **额外勾选** HKG/MFM
- 机场识别：中文城名、英文城名、IATA、多机场城市；数据源优先 **airportsdata** / OurAirports

### 2.2 航线范围

- 仅 **国际/跨境/内地出入境**；排除纯内地城市间国内票
- 任意境外目的地；默认不限日期，可设出行月/日期过滤
- 单程 / 往返 / 未知行程类型均可收录，需标注

### 2.3 来源（合规优先 RSS）

- 航司官网促销/会员日/公告
- 公开 RSS/Atom
- Secret Flying、Fly4Free 等国际优惠源
- 什么值得买国际机票/每日推荐
- 航旅博客与可信社区爆料
- 研究复用：walkabout、RSSHub、changedetection、trafilatura、airportsdata、apprise（评估许可证与维护成本）
- robots/403/429/验证码 → **如实停止**，不绕过

### 2.4 情报结构

类别：官方促销、会员日/优惠码、社区爆料、疑似错价、漏油票、里程促销、其他。  
字段缺失标未知。报道价 ≠ 实时可买价。Bug Fare ≠ 保证出票。  
用户点击原始链接自行查价。

### 2.5 去重 / 排序 / 提醒 / 反馈

- 多源转载合并，保留各来源 URL
- 排序：出发地匹配、来源可信度、新鲜度、截止时间、错价时效、已读/不感兴趣
- 错价/短时促销可高优先提醒；普通优惠进摘要
- 个人：收藏、已读、不感兴趣、可能过期、价格不符（预留多用户反馈字段）

## 3. P2 免费国际机票抽奖（中国出境相关）

- 全球搜索不限主办方国家
- **核心推荐：** 中国内地出发国际机票 / 内地↔境外往返 / 含上述机票的免费旅行套餐
- **不进核心：** 纯国内段机票、汽车、现金、无机票商品
- 出发地不明 → **待核实**，不认定适合内地用户
- 保留：全球发现、官方溯源、OCR、多轮、开放状态、资格三态、入口探测、合规报名辅助
- 七态区分：真实存在 / 内地出境适用 / 免费 / 报名期 / 资格 / 入口可开 / 已报名回执
- 无真实档案不假设 eligible

---

## 4. P3 Trip Benefits（确认行程后）

- 用户 **确认** 真实行程（日期+目的地+人数+兴趣）后才启动扫描
- Demo 行程 **不** 触发正式监控
- 改期/改目的地重匹配；取消停扫；结束归档
- 来源：合法公开攻略/旅游局/商家/交通；禁用违规接口与未授权 Cookie
- 类型：游客折扣、退税、通票、免费景点、餐厅/酒店促销、节庆、省钱策略
- 区分：城市匹配、领取/预约/使用日期、条件、证据、是否真实领取
- 输出：**中文省钱指南**（已核实 vs 待核实）
